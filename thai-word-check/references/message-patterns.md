# แม่แบบข้อความ

ตัวอย่างด้านล่างใช้คำจาก glossary; ถ้าระบบมีรูปแบบเดิมของข้อความประเภทนั้น ให้ยึดของเดิมก่อน ลำดับเมื่อขัดกัน: คำในระบบ → glossary ของโปรเจกต์ → ไฟล์ตัวอย่างโปรเจกต์ → แม่แบบนี้ → glossary กลาง ดังนั้นถ้าแม่แบบนี้ขัดกับ glossary กลางสำหรับข้อความประเภทเดียวกัน ให้ยึดแม่แบบนี้ (เช่น ปุ่ม "ไม่ลบ" ในหน้าต่างยืนยัน แทน "ยกเลิก")

## สำเร็จ
`[ทำอะไรเสร็จ]แล้ว` + (ถ้ามี) ขั้นต่อไป
- "บันทึกแล้ว"
- "นำเข้าข้อมูลเสร็จแล้ว ดูรายการได้เลย"

## กำลังทำงาน
`กำลัง[ทำอะไร]…` + บอกได้ว่าปิดหน้าได้ไหม
- "กำลังส่งออกรายงาน… ปิดหน้านี้ได้ งานยังเดินต่อ"

## ผิดพลาด (เกิดอะไร → เพราะอะไร → ทำอะไรต่อ)
- "บันทึกไม่สำเร็จ เชื่อมต่ออินเทอร์เน็ตไม่ได้ ตรวจสัญญาณแล้วลองอีกครั้ง"
- "เข้าสู่ระบบไม่สำเร็จ รหัสผ่านไม่ถูกต้อง ตรวจรหัสผ่านแล้วลองอีกครั้ง"
- ห้าม: "เกิดข้อผิดพลาด" (ไม่บอกอะไรเลย) ใช้ได้เฉพาะ fallback สุดท้าย + มีทางไปต่อ

## ว่าง (empty state)
`ยังไม่มี[สิ่งนั้น]` + ปุ่มทำสิ่งแรก
- "ยังไม่มีรายการ — เพิ่มรายการใหม่"

## ยืนยันก่อนทำ (ทุกหน้าต่างยืนยัน ทั้งที่ย้อนได้และย้อนไม่ได้)
`[กริยา][สิ่งที่ถูกกระทำ]?` + ผลที่ตามมา + ปุ่มชัด 2 ปุ่ม คือ `[กริยา][สิ่งที่ถูกกระทำ]` / `ไม่[กริยา]`
- หัวข้อ: "ลบรายการนี้?"
- เนื้อหาเมื่อย้อนไม่ได้: "ลบถาวร กู้คืนไม่ได้"
- เนื้อหาเมื่อย้อนได้: บอกว่ากู้คืนได้ที่ไหนและนานเท่าไร เช่น "กู้คืนได้จาก[ชื่อที่เก็บ]ภายใน 30 วัน หลังจากนั้นลบถาวร"
- ปุ่ม: "ลบรายการ" / "ไม่ลบ"

## ฟอร์ม
- label: ชื่อสิ่งที่กรอก (สั้น)
- placeholder: ตัวอย่างค่า ไม่ใช่คำสั่ง
- error ใต้ช่อง: บอกวิธีแก้ ("กรอกรหัสผ่านอย่างน้อย 8 ตัว")

## คำอธิบายระบบ/ข้อจำกัด
ข้อความเตือนหรือข้อจำกัดที่ใช้ซ้ำ ให้ใช้ประโยคเดียวกันทั้งระบบ ไม่ต้องคิดใหม่ทุกหน้า (ดูประโยคที่โปรเจกต์กำหนดไว้ใน glossary ของโปรเจกต์)
